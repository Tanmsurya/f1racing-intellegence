# Formula 1 Race Intelligence & Analytics (2007–2023)

An interactive Formula 1 analytics project built to explore race results, driver performance, team championships, tyre strategies, and circuit data from 2007 to 2023.

🔗 **Live Dashboard:** https://tanmsurya.github.io/f1racing-intellegence/

💻 **GitHub Repository:** https://github.com/Tanmsurya/f1racing-intellegence

## About the Project

This project focuses on analyzing historical Formula 1 data from 17 seasons (2007–2023).

The main aim is to understand how drivers and teams performed over the years and explore different aspects of F1 racing using data visualization.

The project includes interactive dashboards and a Tableau story to make the data easier to understand.

## Dataset

The dataset covers:

- 17 F1 seasons (2007–2023)
- 6,464 race records
- 334 Grand Prix rounds
- 84 drivers and 26 constructors
- 29 racing circuits
- 1,075 DNF records

## Key Features

- **Driver Performance:** Compare drivers based on wins, podiums, points, and performance.
- **Team Comparison:** Analyze constructor performance across different seasons.
- **Tyre Strategy:** Explore tyre compounds, pit stops, and race strategies.
- **Circuit Analysis:** Compare circuits based on length, altitude, turns, and track type.
- **DNF Analysis:** Study race retirements and their possible causes.
- **Podium Analysis:** Explore podium finishes by drivers, teams, and countries.
- **Tableau Story:** An 8-chapter story covering important F1 events and changes between 2007 and 2023.

## Tools & Technologies

- **Tableau:** Data visualization, dashboards, and storytelling.
- **Excel:** Dataset preparation and basic data cleaning.
- **GitHub:** Project storage and version control.
- **HTML, CSS & JavaScript:** Web dashboard.

## Key Observations

- Mechanical issues account for a major share of driver retirements.
- Mercedes dominated the Constructors' Championship during the hybrid era.
- Different regulation changes had a major impact on team performance.
- Circuit characteristics such as altitude and track length can influence race strategy.
